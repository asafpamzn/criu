Step 7: Timers

Three types of timers, all dumped via the parasite.

Interval Timers (itimers)

ret = parasite_dump_itimers_seized(
    parasite_ctl, item);
  • Three classic timers: ITIMER_REAL, ITIMER_VIRTUAL, ITIMER_PROF
  • Read via getitimer() inside the parasite
  • Captures both interval and remaining time

POSIX Timers

// First: enumerate from /proc
ret = parse_posix_timers(pid, &proc_args);
// Then: read values via parasite
ret = parasite_dump_posix_timers_seized(
    &proc_args, parasite_ctl, item);
  • Enumerated from /proc/PID/timers
  • Values read via timer_gettime() in parasite
  • Captures: clock ID, signal number, overrun count, interval, remaining
🕐 Timer values are relative — on restore, CRIU recalculates the remaining time based on how long the process was frozen. Timers must fire at the right wall-clock moment after restore, not replay the exact remaining value.
