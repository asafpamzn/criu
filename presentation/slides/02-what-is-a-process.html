What Defines a Running Process?

A Linux process is scattered state across the kernel. CRIU must capture all of it.

🧠Memory
Virtual memory areas (VMAs) + actual page contents — the biggest chunk
🧵Threads
Each thread's CPU registers, TLS, stack, scheduling policy, seccomp filters
📄File Descriptors
Open files, sockets, pipes, eventpolls, timerfd — everything in /proc/PID/fd/
🚦Signals
Signal handler table (sigactions) + pending signal queues (private + shared)
⏱️Timers
Interval timers (itimers) and POSIX timers — must fire at the right time after restore
🔐Credentials & Security
UID/GID, capabilities, LSM profiles, rlimits, loginuid, oom_score_adj
📁Filesystem Context
Current working directory, root directory, umask
🏷️Namespaces & Cgroups
PID, net, mount, IPC, UTS, user, cgroup, time namespace memberships
