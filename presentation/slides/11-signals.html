Step 6: Signals

Two distinct parts: the handler table and the pending queues.

Signal Handlers (sigactions)

// Via parasite — must be read from
// inside the process context
ret = parasite_dump_sigacts_seized(
    parasite_ctl, item);
  • Calls rt_sigaction() for each of 64 signals
  • Captures: handler address, flags, mask, restorer
  • Must run inside process — handlers are per-process state
  • Saved in the core image

Pending Signal Queues

// Via ptrace — read from outside
ret = dump_task_signals(pid, item);
  • Uses PTRACE_PEEKSIGINFO
  • Reads signals in batches of 32
  • Private signals — per-thread queue (for each thread)
  • Shared signals — process-wide queue (only once)
  • Full siginfo_t preserved for each pending signal
⚠️ Signals are dumped before parasite injection (step 5 in dump_one_task) because the injection itself sends SIGSTOP/signals that would pollute the queues. Signal handlers are dumped after injection (step 11) via the parasite.
