Phase 1: Enumerate

collect_fds() reads /proc/PID/fd/ directory

  • Builds array of FD numbers
  • Doesn't read content yet — just numbers
  • Grows buffer dynamically (PAGE_SIZE chunks)

Phase 2: Dump via Parasite

dump_task_files_seized() uses the parasite to:

  • Drain FDs from the process into CRIU
  • Read detailed fdinfo for each FD
  • Classify: regular file, socket, pipe, eventpoll, timerfd, signalfd, etc.
  • Dump type-specific metadata (e.g. socket addresses, pipe buffers)
🔗 If shared_fdtable(item) is true, this process shares its FD table with its parent (CLONE_FILES) — no need to dump it again.
