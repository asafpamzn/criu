Step 1: Process Identity & Metadata

// First thing dump_one_task does:
ret = parse_pid_stat(pid, &pps_buf);

Reads /proc/PID/stat to get:

Identity
pid, sid, pgid, comm (command name), flags
Code & Data Bounds
start_code, end_code, start_data, end_data, start_stack, start_brk
Arguments & Environment
arg_start, arg_end, env_start, env_end
Exit Code
For zombies — captured in task_state + exit_code
Personality
Read from /proc/PID/personality — execution domain flags
Misc
loginuid, oom_score_adj, child_subreaper, dumpable flag
📌 The pps_buf (proc_pid_stat) is reused later by dump_task_mm and dump_task_core_all — it's the source of truth for many metadata fields.
