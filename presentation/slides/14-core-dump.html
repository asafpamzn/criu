Step 9: Core Dump — Task Metadata

ret = dump_task_core_all(parasite_ctl, item, &pps_buf, cr_imgset, &misc);

The "core" image is the central record for each task — it ties together everything.

What dump_task_core_all collects

  • Personality — execution domain (e.g., 32-bit compat)
  • comm — command name, flags, task state
  • Credentials — LSM profile, sockcreate context
  • Stop signal — if task was TASK_STOPPED
  • Thread leader registers — via parasite_dump_thread_leader_seized()
  • loginuid — for SSH audit trail
  • oom_score_adj — OOM killer priority
  • rlimits — all resource limits (RLIMIT_NOFILE, etc.)
  • child_subreaper — prctl(PR_SET_CHILD_SUBREAPER)
  • membarrier registration — membarrier flags
  • Cgroup set — cgroup paths for root task

The rlimits dump

static int dump_task_rlimits(int pid,
                  TaskRlimitsEntry *rls) {
  for (res = 0; res < rls->n_rlimits; res++) {
    struct rlimit64 lim;
    syscall(__NR_prlimit64, pid, res,
            NULL, &lim);
    rls->rlimits[res]->cur =
        encode_rlim(lim.rlim_cur);
    rls->rlimits[res]->max =
        encode_rlim(lim.rlim_max);
  }
}

All RLIMIT_* values are read via prlimit64 syscall — no parasite needed for this one.
