Dirty Pages: Tracking Methods

Iterative Pre-dump (standard CRIU)

Soft-dirty + clear_refs
Round 1: Dump ALL pages, clear dirty bits
Round 2: Dump only pages dirtied since round 1
Round 3: Even fewer dirty pages...
Final dump: Freeze + dump remaining dirty pages

Each round transfers less data → shorter final freeze.
How it works
The kernel maintains a soft-dirty bit per PTE.
Writing "4" to /proc/PID/clear_refs clears all soft-dirty bits.
Reading /proc/PID/pagemap reveals which pages got dirty since the last clear.

COW Mode Alternative

Userfaultfd write-protect (UFFD-WP)
Instead of querying kernel dirty bits, COW mode write-protects every VMA via userfaultfd.

On first write → CPU traps → CRIU snapshots the original page → allows the write.

Real-time tracking — no page table walk needed.
Key difference
Standard COW
Track method soft-dirty + pagemap UFFD write-protect

Freeze cost 2-5s (200GB) ~0ms
