Path A: PAGEMAP_SCAN ioctl (kernel 6.x+)

// pagemap-cache.c — pmc_fill()
ret = ioctl(pmc->fd, PAGEMAP_SCAN, &args);
// Returns sparse array of page_region structs:
//   { start, end, categories }
// Only regions with matching categories returned!

Kernel walks page tables internally, returns only dirty ranges. Clean regions are skipped entirely.

// should_dump_page() — skip optimization:
if (vaddr < pmc->regs[idx].start) {
    page_info->next = pmc->regs[idx].start;
    return 0;  // → generate_iovs jumps ahead!
}

Path B: pread(/proc/PID/pagemap) (older kernels)

// pagemap-cache.c — pmc_fill()
pread(pmc->fd, pmc->map, size, off);
// Returns 8 bytes per page — ALL pages, not just dirty
// 200GB = 52M pages × 8 bytes = 400MB of pagemap data

Every page gets an entry. should_dump_page() checks bit 55:

// should_dump_page() — check each PTE entry:
u64 pme = pmc->map[PAGE_PFN(vaddr - pmc->start)];
if ((pme & (PME_PRESENT | PME_SWAP)) && !zero)
    page_info->softdirty = pme & PME_SOFT_DIRTY;
// bit 55 of the 64-bit pagemap entry
First pre-dump problem: No prior clear_refs → ALL pages have softdirty=1. And has_parent=false (no parent image). So every page is classified as "must dump" regardless of PAGEMAP_SCAN optimizations.
