Step 5: Memory Pages — The Heavy Lift

mdc.pre_dump = false;
mdc.lazy = opts.lazy_pages;
mdc.stat = &pps_buf;
mdc.parent_ie = parent_ie;

ret = parasite_dump_pages_seized(item, &vmas, &mdc, parasite_ctl);

What gets dumped?

  • Private anonymous pages — heap, stack, mmap(MAP_PRIVATE|MAP_ANON)
  • Private file-backed pages — COW'd pages of shared libraries
  • Shared anonymous pages — shmem regions
  • File-backed clean pages are not dumped — they can be re-read from disk

How?

  • process_vm_readv() — bulk read from target address space
  • Pages flow through a page-pipe (splice-based zero-copy)
  • Written to image files or sent to page-server

Optimization: Incremental Dumps

If parent_ie is set (previous dump exists):

  • Only pages that changed since last dump are written
  • Uses pagemap to detect dirty pages
  • Unchanged pages reference parent image

Lazy Pages Mode

When mdc.lazy = true:

  • Pages are not written to images
  • Instead, transferred on-demand via userfaultfd
  • Restore starts immediately, pages arrive as needed
💾 For a 100GB Valkey instance, this step transfers ~100GB of data. At 1,700 MB/s with 8 TCP streams, it takes ~58 seconds.
