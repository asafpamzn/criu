Summary: dump_one_task Timeline

Complete flow from frozen process to image files on disk.

Process frozen (ptrace SEIZE) — all threads stopped
parse_pid_stat — read /proc/PID/stat
collect_mappings — parse smaps, build VMA list
collect_fds — enumerate /proc/PID/fd/
parse_posix_timers — read /proc/PID/timers
dump_task_signals — PTRACE_PEEKSIGINFO
dump_task_rseq — PTRACE_GET_RSEQ_CONFIGURATION
parasite_infect_seized — inject PIE blob ▶
dump_task_files_seized — drain FDs via parasite
parasite_dump_pages_seized — read all memory pages ★
parasite_dump_sigacts_seized — rt_sigaction × 64
parasite_dump_itimers + posix_timers
dump_task_core_all — regs, creds, rlimits, personality
compel_stop_daemon — stop parasite
dump_task_threads — per-thread registers, TLS, seccomp
compel_cure — remove parasite, restore registers
dump_task_mm — VMA metadata, auxv, exe link
dump_task_fs — cwd, root, umask
Process resumed (or killed, depending on --leave-running)
█ = parasite active    █ = process frozen boundary    ★ = heaviest step (memory pages)
