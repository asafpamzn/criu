smaps: Page States

Three Key Page States

Referenced
Pages accessed (read or written) recently. The kernel tracks this for its LRU page reclaim — unreferenced pages get swapped out first. Not directly used by CRIU — informational only.
Anonymous
Pages with NO file backing — they exist only in RAM (and swap). Created by: heap (brk/mmap(MAP_ANONYMOUS)), stack, COW'd pages after fork(). All anonymous pages must be dumped by CRIU — there's no file to re-read them from.
LazyFree
Pages marked with madvise(MADV_FREE). The process says "I don't need this data anymore, but don't bother freeing now — reclaim when you need memory." Used by jemalloc to return pages cheaply.

smaps Memory Accounting

Size:               2048 kB
Rss:                1024 kB  ← pages in RAM
Pss:                 512 kB  ← proportional share
Shared_Clean:        256 kB
Shared_Dirty:          0 kB
Private_Clean:       256 kB
Private_Dirty:       512 kB  ← CRIU must dump these
Referenced:         1024 kB
Anonymous:          1024 kB  ← no file backing
LazyFree:              0 kB
Swap:                  0 kB
What CRIU uses these for
Private_Dirty — pages modified, must dump
Anonymous — no file backing, must dump
Swap — paged out, read from swap
RSS/PSS — size estimation for page-pipe allocation
