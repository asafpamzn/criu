Personality Flags & Why CRIU Needs Them

Personality Flags (OR'd with base)

ADDR_NO_RANDOMIZE (0x0040000)
Disables ASLR (Address Space Layout Randomization). Stack, mmap, heap, and vDSO addresses become deterministic. Used for debugging or by processes that need reproducible memory layouts.
ADDR_LIMIT_32BIT (0x0800000)
Restricts mmap to the low 32-bit address range. Ensures all pointers fit in 32 bits.
SHORT_INODE (0x1000000)
Report 16-bit inode numbers. Compatibility for ancient filesystems.
READ_IMPLIES_EXEC (0x0400000)
All readable pages are also executable. Legacy behavior for old binaries without proper ELF flags. Security concern — CRIU must preserve it exactly.
🔑 Why CRIU needs this: A 32-bit Valkey on a 64-bit host uses PER_LINUX32. Restoring without the correct personality would break syscall numbering, uname output, and address space layout. A process with ADDR_NO_RANDOMIZE restored with ASLR enabled would get different memory addresses — potentially crashing.
