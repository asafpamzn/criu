smaps: VmFlags — 2-Letter Codes

The VmFlags: line encodes kernel vm_flags. CRIU parses these in parse_vma_vmflags().

mmap() Flags

Restored via mmap arguments:

gdMAP_GROWSDOWNStack — grows downward
loMAP_LOCKEDmlock'd — can't be swapped
nrMAP_NORESERVENo swap reservation
htMAP_HUGETLBHuge pages (2MB/512KB)
dpMAP_DROPPABLEKernel can discard under pressure

Special Kernel Flags

ioVM_IOI/O mapped (device MMIO) — can't vmsplice
pfVM_PFNMAPRaw PFN mapped — can't vmsplice
ssShadow StackIntel CET / ARM BTI security

madvise() Flags

Restored via madvise calls after mmap:

srMADV_SEQUENTIALAggressive readahead
rrMADV_RANDOMDisable readahead
dcMADV_DONTFORKDon't copy on fork()
ddMADV_DONTDUMPExclude from core dumps
mgMADV_MERGEABLEEnable KSM dedup
hgMADV_HUGEPAGEUse THP
nhMADV_NOHUGEPAGEDon't use THP
wfMADV_WIPEONFORKZero in child after fork
Restore order matters: First mmap() with the mmap flags, then madvise() for each advisory flag. VmFlags tell CRIU which madvise calls to replay.
