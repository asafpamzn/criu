TLS: Where the State Lives

TLS state lives entirely in userspace memory — CRIU captures it automatically.

What CRIU dumps for a TLS connection
1. TCP layer (kernel) → TCP_REPAIR: seq/ack numbers, send/receive queues containing encrypted bytes

2. TLS layer (userspace) → memory pages: OpenSSL's SSL_CTX, SSL structs, session keys, read/write buffers
CRIU doesn't know about TLS
CRIU has no TLS-specific code. It dumps all memory pages and all TCP sockets. The OpenSSL structs come along automatically as part of the heap. The encrypted bytes in TCP queues come along via TCP_REPAIR. TLS is free.
