How Image Layers Stack

Incremental pre-dumps build a stack of image layers. Each layer only contains dirty pages.

Pre-dump 1 (parent) — no baseline
has_parent=false → ALL present pages dumped
Page A Page B zero Page D
↓ clear_refs → process runs → some pages modified
Pre-dump 2 (incremental) — has parent
Only dirty pages + parent holes for unchanged pages
hole→A Page B' zero hole→D
↓ clear_refs → process runs → fewer pages modified
Final dump — smallest delta
Mostly parent holes, few dirty pages
hole→A hole→B' zero Page D'
Each successive pre-dump transfers less data as the dirty set converges. The final dump during freeze is minimal — only the pages modified since the last pre-dump.
