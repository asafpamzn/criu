Personality: What Is It?

static int get_task_personality(pid_t pid, u32 *personality) {
    fd = open_proc(pid, "personality");
    ret = read(fd, loc_buf, sizeof(loc_buf) - 1);
    *personality = atoi(loc_buf);
}

A 32-bit value read from /proc/PID/personality that controls how the kernel behaves for this process. It's a bitmask combining a base personality (low byte) with flags (high bytes).

Set via personality() syscall or inherited from parent. Typically set by the dynamic loader or by exec of a 32-bit binary on a 64-bit kernel.

Common Base Personalities

PER_LINUX (0x0000)
Default. Standard Linux behavior. 64-bit process on 64-bit kernel, or 32-bit on 32-bit kernel.
PER_LINUX32 (0x0008)
32-bit compatibility mode on a 64-bit kernel. uname -m reports i686 instead of x86_64. Syscall numbers follow 32-bit ABI.
PER_LINUX_32BIT
Limits virtual address space to 32-bit range. Used for some legacy binaries that assume 32-bit pointers.
