COW WP_ASYNC Convergence Timeline

Phase 1: Bulk Transfer (source running)

① Dump + Early Resume (~51ms freeze)
ptrace seize → capture metadata (regs, FDs, signals, timers) → parasite pages → SIGCONT
Source is running again. All non-memory state captured.
② Linear page transfer (~58s for 100GB)
8 TCP streams × process_vm_readv batches (512 pages) + LZ4 compress → send
WP_ASYNC: kernel auto-clears WP on write, PAGE_IS_WRITTEN bit set
Source serving traffic throughout. Writes tracked by kernel.

Phase 2: Convergence

③ Wait for idle threads
Poll /proc/PID/task/*/syscall — wait until all threads in epoll/futex/nanosleep
Ensures no thread holds allocator locks (prevents deadlock on SIGSTOP).
④ First freeze: SIGSTOP (~1ms)
kill(source_pid, SIGSTOP) → PAGEMAP_SCAN(PAGE_IS_WRITTEN) per VMA
Atomic scan: finds all pages dirtied since bulk transfer.
⑤ Fork snapshot
Inject clone(SIGCHLD) via ptrace → child inherits COW memory snapshot
SIGCONT source immediately — fork has the consistent snapshot
Source responsive again in ~1ms. Fork lives ~2s.
⑥ Read dirty pages from fork
process_vm_readv from fork PID across 8 TCP streams
Temporally consistent: all pages from same point in time.
Kill fork when done.

Phase 3: Final Convergence

⑦ Post-fork dirty scan
Source was running during fork read (~2s). Scan for new dirty pages.
Send across 8 streams. Typically ~86K pages (vs ~26M in bulk).
⑧ Second freeze: SIGSTOP (~1ms)
Final PAGEMAP_SCAN — should find near-zero dirty pages.
Send remaining dirty pages.
⑨ Detect new VMAs
Compare live /proc/PID/maps with dump-time VMA list.
New anonymous rw- VMAs → send PS_IOV_VMA_DIFF header + page data.
Replica: mmap(MAP_FIXED) via ptrace to create them.
⑩ SIGCONT + Close
Resume source. Send PS_IOV_CLOSE on all 8 streams.
Migration complete. Total cutover: ~1ms.

Why This Works

Non-memory state Immutable after dump (process was frozen)
Memory pages WP_ASYNC tracks writes, PAGEMAP_SCAN finds them
Consistency Fork snapshot reads all dirty pages atomically
New VMAs VMA diff protocol + ptrace injection on replica
libc safety Arena pages excluded from convergence
