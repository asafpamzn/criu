pre_dump_one_task — Step by Step

Lightweight pass: memory pages only, process stays alive

1
collect_mappings(pid, &vmas, NULL)
Parse /proc/PID/smaps → build VMA list. NULL = skip file metadata.
2
parasite_infect_seized(pid, item, &vmas)
Inject parasite code into the process (Compel)
3
parasite_fixup_vdso() + parasite_dump_misc_seized()
Fix vDSO refs, read brk/pid/umask — minimal metadata
4
predump_task_files(pid)
Pre-cache file metadata for next iteration
5
parasite_dump_pages_seized(item, &vmas, &mdc, ctl)
Read dirty memory pages — the main work. mdc.pre_dump = true
6
compel_cure_remote(parasite_ctl)
Remove parasite — process resumes running
💡 Pre-dump only reads pages — it doesn't dump threads, FDs, signals, or timers. The process continues running so these keep changing anyway.
