The Parasite — CRIU's Secret Weapon

Some state can only be read from inside the process. CRIU injects code to do it.

CRIU
coordinator process
→
Target Process
ptrace-seized, frozen
→
Parasite Code
PIE blob injected
into target's address space

Lifecycle

1
parasite_infect_seized() — mmap space in target, copy PIE blob, start daemon thread
2
RPC commands — CRIU sends commands, parasite executes syscalls in target context
3
compel_stop_daemon() — stop the parasite daemon
4
compel_cure() — munmap the blob, restore original registers

What the parasite collects

  • Signal handlers — rt_sigaction() for all 64 signals
  • Timers — getitimer(), timer_gettime()
  • File descriptors — drains FDs via SCM_RIGHTS
  • Memory pages — process_vm_readv()
  • Misc — brk, pid, sid, pgid, umask, dumpable
  • Credentials — real/effective/saved UIDs/GIDs
  • Thread leader state — registers, TLS
🧬 The parasite is built by Compel — a separate subproject that generates Position-Independent Executables for injection. See compel/ directory.
