Page Classification: Three Categories

During pagemap scanning, every page falls into one of three categories.

① Skipped (zero/unmapped)
Page is not present in RAM or swap, or is the kernel zero page. Silently skipped — never enters the page-pipe at all.
// should_dump_page():
if (!(pme & (PME_PRESENT | PME_SWAP)))
    skip;  // not in RAM, not in swap
if (__page_is_zero(pme))
    skip;  // kernel zero page
Restore naturally has zeros for these addresses. No action needed.
② Parent Hole (clean page)
Page exists in memory but is NOT soft-dirty since last clear_refs. Already in parent image → tell restore to get it from there.
// generate_iovs():
if (has_parent && page_in_parent(softdirty))
    page_pipe_add_hole(pp, vaddr,
                       PP_HOLE_PARENT);
Entered into page-pipe as a hole. Restore fetches from parent image layer.
③ Dirty Page (must dump)
Page exists in memory AND has been modified (soft-dirty set). Must be captured into the current image.
// generate_iovs():
page_pipe_add_page(pp, vaddr, ppb_flags);
// ppb_flags may include PPB_LAZY
On first pre-dump ALL present pages are dirty (no baseline).
Key distinction: Skipped = not in memory at all (zeros). Parent hole = in memory but unchanged since parent image. Dirty = in memory and modified. Don't confuse skipped pages with parent holes!
