Step 2: Memory Mappings (VMAs)

ret = collect_mappings(pid, &vmas, dump_filemap);

What are VMAs?

Virtual Memory Areas — each contiguous region of the process's address space:

  • Code — .text (executable, read-only)
  • Data — .data, .bss, heap
  • Stack — per-thread stacks
  • File-mapped — mmap'd files, shared libs
  • Anonymous — malloc'd memory
  • Shared memory — SysV IPC, memfd
  • Special — vDSO, vvar, vsyscall

What does collect_mappings do?

  1. Parses /proc/PID/smaps (or /proc/PID/maps in CLONE mode)
  2. Builds a linked list of vma_area structs
  3. For file-backed VMAs, calls dump_filemap() to record the backing file
  4. Collects MADV_GUARD_INSTALL pages
  5. Counts private pages (for page-pipe sizing)
⚡ In pre_dump the second arg is NULL — no file metadata needed.
In dump it's dump_filemap — must identify every backing file.
