Two Dump Modes

pre_dump_one_task

Iterative Memory Pre-copy

  • Only dumps memory pages
  • Process keeps running after each pass
  • Tracks dirty pages between iterations
  • Used for live migration — reduces final freeze time
  • No files, signals, threads, or timers

Typical: run 1-3 pre-dump passes, then one full dump

dump_one_task

Full Checkpoint

  • Captures everything
  • Process is frozen during dump
  • ~20 distinct collection steps
  • Produces complete image set
  • Sufficient to recreate the process from scratch

One call per process in the tree
