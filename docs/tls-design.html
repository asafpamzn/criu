1. Motivation & Goals

When migrating a Valkey process via CRIU COW dump, all page data (hundreds of GBs) flows over the network between the source and target machines. This data includes the full memory contents of Valkey — including encryption keys, user data, authentication tokens, and in-flight queries.

Requirements
  • Encryption: All data in transit must be encrypted (TLS 1.2+)
  • Mutual Authentication: Both source and target must present valid X.509 certificates
  • Multi-connection support: P3 parallel connections (up to 15 threads) must each have independent TLS sessions
  • Performance: TLS overhead must not become the bottleneck (currently LZ4 compression + tcp_sendmsg dominate)
  • Consistency with Valkey: Use the same certificate infrastructure that Valkey itself uses

2. Current State Analysis

Existing TLS Implementation (Upstream CRIU)

CRIU already has basic TLS support using GnuTLS, but it has a critical limitation for COW mode:

3. Valkey TLS Model (Reference)

Valkey (and Redis 6+) implements TLS using OpenSSL with a per-connection architecture. Key design patterns to replicate:

Key Valkey Pattern: Shared Context, Per-Connection Sessions

/* Valkey: one SSL_CTX shared across all connections */
SSL_CTX *ctx = SSL_CTX_new(TLS_method());
SSL_CTX_use_certificate_file(ctx, cert_file, SSL_FILETYPE_PEM);
SSL_CTX_use_PrivateKey_file(ctx, key_file, SSL_FILETYPE_PEM);
SSL_CTX_load_verify_locations(ctx, ca_cert_file, ca_cert_dir);

/* Per-connection: each socket gets its own SSL object */
SSL *ssl = SSL_new(ctx);      /* Lightweight - shares ctx config */
SSL_set_fd(ssl, socket_fd);
SSL_connect(ssl);             /* or SSL_accept() on server side */

/* I/O is per-connection - thread-safe */
SSL_write(ssl, data, len);
SSL_read(ssl, buf, len);

This is exactly the model we need for CRIU COW: one shared credential context, but 15+ independent TLS sessions for parallel P3 threads.

6. Per-Connection TLS (Thread-Safe)

Core Design: struct tls_conn

/* New: Per-connection TLS state (replaces global singleton) */
struct tls_conn {
    gnutls_session_t session;
    int socket_fd;
    int flags;             /* For push/pull callbacks */
    bool is_server;
};

/* Shared credential context (init once, use by all connections) */
struct tls_context {
    gnutls_certificate_credentials_t x509_cred;
    bool initialized;
    pthread_mutex_t init_lock;  /* Protects one-time init */
};

/* Global shared context */
static struct tls_context g_tls_ctx;

/* API */
int tls_global_init(void);                           /* Load certs once */
struct tls_conn *tls_conn_new(int sockfd, bool is_server);  /* Per-socket */
void tls_conn_free(struct tls_conn *conn);
ssize_t tls_conn_send(struct tls_conn *conn, const void *buf, size_t len, int flags);
ssize_t tls_conn_recv(struct tls_conn *conn, void *buf, size_t len, int flags);

Thread Safety Model

Concurrency Guarantees
  • Credential loading: Done once during startup via tls_global_init(). Protected by mutex for lazy init.
  • Session creation: tls_conn_new() creates independent GnuTLS sessions. Each session has its own state.
  • I/O operations: Each P3 thread owns its tls_conn exclusively — no locking needed for send/recv.
  • GnuTLS thread safety: GnuTLS is thread-safe when sessions are not shared. gnutls_global_init() called once.

Integration with Existing Code

8. Implementation Plan

Phase 1: Per-Connection TLS Core (Replace Singleton)

Step 1: New tls_conn API

Create criu/tls-conn.c and criu/include/tls-conn.h with the per-connection TLS implementation. Keep the old tls.c as a thin wrapper for backward compatibility with non-COW code paths.

/* criu/include/tls-conn.h */
#ifndef __CR_TLS_CONN_H__
#define __CR_TLS_CONN_H__

#include <stdbool.h>
#include <sys/types.h>

struct tls_conn;

/* Initialize global TLS context (load certificates). Call once. */
int tls_global_init(void);

/* Shutdown global TLS context. Call at exit. */
void tls_global_deinit(void);

/* Create a new TLS connection on an existing socket.
 * Performs handshake and certificate verification.
 * Returns NULL on failure. */
struct tls_conn *tls_conn_new(int sockfd, bool is_server);

/* Close TLS session and free resources. Does NOT close the socket. */
void tls_conn_free(struct tls_conn *conn);

/* Send data over TLS connection. Same semantics as send(). */
ssize_t tls_conn_send(struct tls_conn *conn, const void *buf,
                      size_t len, int flags);

/* Receive data over TLS connection. Same semantics as recv(). */
ssize_t tls_conn_recv(struct tls_conn *conn, void *buf,
                      size_t len, int flags);

/* Blocking send-all: retries short writes until all bytes sent. */
ssize_t tls_conn_send_all(struct tls_conn *conn, const void *buf,
                          size_t len, int flags);

/* Blocking recv-all: retries until all bytes received. */
ssize_t tls_conn_recv_all(struct tls_conn *conn, void *buf,
                          size_t len, int flags);

#endif /* __CR_TLS_CONN_H__ */

9. New TLS API

Full Implementation: criu/tls-conn.c

#include <gnutls/gnutls.h>
#include <pthread.h>
#include "cr_options.h"
#include "tls-conn.h"
#include "criu-log.h"

struct tls_conn {
    gnutls_session_t session;
    int socket_fd;
    int io_flags;
};

static struct {
    gnutls_certificate_credentials_t x509_cred;
    bool initialized;
    pthread_once_t once;
} g_tls_ctx = { .once = PTHREAD_ONCE_INIT };

static void _tls_global_init_once(void)
{
    gnutls_global_init();

    gnutls_certificate_allocate_credentials(&g_tls_ctx.x509_cred);

    /* Load CA trust */
    if (opts.tls_cacert)
        gnutls_certificate_set_x509_trust_file(
            g_tls_ctx.x509_cred, opts.tls_cacert, GNUTLS_X509_FMT_PEM);
    else
        gnutls_certificate_set_x509_system_trust(g_tls_ctx.x509_cred);

    /* Load CRL if provided */
    if (opts.tls_cacrl)
        gnutls_certificate_set_x509_crl_file(
            g_tls_ctx.x509_cred, opts.tls_cacrl, GNUTLS_X509_FMT_PEM);

    /* Load our cert + key */
    gnutls_certificate_set_x509_key_file(
        g_tls_ctx.x509_cred,
        opts.tls_cert ? opts.tls_cert : CRIU_CERT,
        opts.tls_key ? opts.tls_key : CRIU_KEY,
        GNUTLS_X509_FMT_PEM);

    g_tls_ctx.initialized = true;
}

int tls_global_init(void)
{
    pthread_once(&g_tls_ctx.once, _tls_global_init_once);
    return g_tls_ctx.initialized ? 0 : -1;
}

/* Push/pull callbacks - use conn->socket_fd */
static ssize_t _conn_push(gnutls_transport_ptr_t ptr,
                           const void *data, size_t sz)
{
    struct tls_conn *conn = (struct tls_conn *)ptr;
    return send(conn->socket_fd, data, sz, conn->io_flags);
}

static ssize_t _conn_pull(gnutls_transport_ptr_t ptr,
                           void *data, size_t sz)
{
    struct tls_conn *conn = (struct tls_conn *)ptr;
    return recv(conn->socket_fd, data, sz, conn->io_flags);
}

struct tls_conn *tls_conn_new(int sockfd, bool is_server)
{
    struct tls_conn *conn;
    unsigned int flags;
    int ret;

    if (!g_tls_ctx.initialized)
        tls_global_init();

    conn = xmalloc(sizeof(*conn));
    if (!conn)
        return NULL;

    conn->socket_fd = sockfd;
    conn->io_flags = 0;

    flags = is_server ? GNUTLS_SERVER : GNUTLS_CLIENT;
    ret = gnutls_init(&conn->session, flags);
    if (ret != GNUTLS_E_SUCCESS)
        goto err_free;

    gnutls_credentials_set(conn->session,
                           GNUTLS_CRD_CERTIFICATE, g_tls_ctx.x509_cred);
    gnutls_set_default_priority(conn->session);

    /* Transport callbacks use conn pointer */
    gnutls_transport_set_ptr(conn->session, conn);
    gnutls_transport_set_push_function(conn->session, _conn_push);
    gnutls_transport_set_pull_function(conn->session, _conn_pull);

    if (is_server) {
        gnutls_certificate_server_set_request(
            conn->session, GNUTLS_CERT_REQUIRE);
        gnutls_certificate_send_x509_rdn_sequence(conn->session, 1);
    }

    /* Perform handshake */
    do {
        ret = gnutls_handshake(conn->session);
    } while (ret == GNUTLS_E_AGAIN || ret == GNUTLS_E_INTERRUPTED);

    if (ret != GNUTLS_E_SUCCESS)
        goto err_session;

    /* Verify peer certificate */
    if (!is_server || opts.tls_mutual_auth) {
        unsigned status;
        const char *hostname = opts.tls_no_cn_verify ? NULL : opts.addr;
        ret = gnutls_certificate_verify_peers3(
            conn->session, hostname, &status);
        if (ret != GNUTLS_E_SUCCESS || status != 0)
            goto err_session;
    }

    return conn;

err_session:
    gnutls_deinit(conn->session);
err_free:
    xfree(conn);
    return NULL;
}

ssize_t tls_conn_send(struct tls_conn *conn,
                       const void *buf, size_t len, int flags)
{
    conn->io_flags = flags;
    ssize_t ret = gnutls_record_send(conn->session, buf, len);
    conn->io_flags = 0;
    if (ret < 0) {
        errno = (ret == GNUTLS_E_AGAIN) ? EAGAIN : EIO;
        return -1;
    }
    return ret;
}

ssize_t tls_conn_recv(struct tls_conn *conn,
                       void *buf, size_t len, int flags)
{
    conn->io_flags = flags;
    ssize_t ret = gnutls_record_recv(conn->session, buf, len);
    conn->io_flags = 0;
    if (ret < 0) {
        errno = (ret == GNUTLS_E_AGAIN) ? EAGAIN : EIO;
        return -1;
    }
    return ret;
}

ssize_t tls_conn_send_all(struct tls_conn *conn,
                           const void *buf, size_t len, int flags)
{
    const char *cursor = buf;
    size_t remaining = len;

    while (remaining > 0) {
        ssize_t ret = tls_conn_send(conn, cursor, remaining, flags);
        if (ret < 0) {
            if (errno == EINTR) continue;
            return -1;
        }
        if (ret == 0) return len - remaining;
        cursor += ret;
        remaining -= ret;
    }
    return len;
}

void tls_conn_free(struct tls_conn *conn)
{
    if (!conn) return;
    gnutls_bye(conn->session, GNUTLS_SHUT_WR);
    gnutls_deinit(conn->session);
    xfree(conn);
}

void tls_global_deinit(void)
{
    if (g_tls_ctx.initialized) {
        gnutls_certificate_free_credentials(g_tls_ctx.x509_cred);
        gnutls_global_deinit();
        g_tls_ctx.initialized = false;
    }
}

Performance Considerations
  • Handshake overhead: ~2-5ms per connection. With 15 P3 threads connecting in parallel, total is still ~5ms (parallel handshakes).
  • Encryption throughput: AES-256-GCM on modern CPUs (AES-NI): ~5-10 GB/s per core. The bottleneck remains tcp_sendmsg and LZ4 compression, not TLS.
  • Record overhead: ~29 bytes per TLS record. With batch sizes of 256KB+, this is negligible (<0.01%).
  • Memory: ~100KB per GnuTLS session. 15 P3 threads = ~1.5MB total — trivial vs the GB of page data.
  • Session resumption: Not needed; connections are long-lived (entire migration duration).
